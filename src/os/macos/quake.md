0. Install https://www.macsourceports.com/game/quake. Link via https://github.com/Novum/vkQuake.
1. Close Steam.
2. In the web browser open `steam://open/console` or `open -a Steam --args -console`.
3. In Console tab: `download_depot 2310 2311`.
4. `ln -s "$HOME/Library/Application Support/Steam/Steam.AppBundle/Steam/Contents/MacOS/steamapps/content/app_2310/depot_2311/id1" /Applications/`.
5. Run vkQuake.
